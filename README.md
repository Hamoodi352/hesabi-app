# نظام الفواتير والمبيعات والمخزون

تطبيق ويب محلي بواجهة عربية لإدارة:

- فواتير المبيعات والمشتريات
- ملفات العملاء والموردين وكشف الحساب
- المخزون والأصناف وحدود التنبيه
- حركة مخزون تفصيلية ومخزون محجوز للفواتير غير المسددة
- الأرباح وقيمة المخزون
- تقارير الفترة وأفضل الأصناف مبيعًا
- موقف المدفوعات والذمم المدينة والدائنة
- تسجيل دفعات متعددة على كل فاتورة مع طريقة الدفع والمرجع
- المصروفات العامة وحساب صافي الربح بعدها
- الصندوق والبنك وأرصدة الحسابات وحركة النقد
- صلاحيات المستخدمين وسجل النشاط
- طباعة الفواتير وتصدير نسخة احتياطية JSON
- استرجاع نسخة احتياطية من ملف JSON
- تسجيل دخول عبر Backend محلي مع كلمات مرور مشفرة
- ألوان مالية قابلة للتخصيص: الأخضر للمبالغ المطلوبة لي، والأحمر للمبالغ المطلوبة مني
- معالجة الدفعات الزائدة وتحويل الفرق إلى رصيد دائن عند الموافقة
- تصنيفات محفوظة للمصروفات تظهر في الإدخالات التالية

## التشغيل

افتح الملف `index.html` في المتصفح مباشرة.

البيانات تحفظ تلقائيًا داخل المتصفح باستخدام `localStorage`. إذا فتحت التطبيق من متصفح آخر ستبدأ بيانات جديدة، ويمكن استخدام زر التصدير للاحتفاظ بنسخة احتياطية.

## التشغيل مع تسجيل الدخول والـ Backend

شغل الخادم المحلي:

```powershell
node server.js
```

ثم افتح:

```text
http://localhost:4173
```

بيانات الدخول الافتراضية:

- المدير: `admin@example.com` / `admin123`
- المحاسب: `accountant@example.com` / `accountant123`
- الكاشير: `cashier@example.com` / `cashier123`
- الموظف: `employee@example.com` / `employee123`

قاعدة البيانات المحلية تحفظ في `data/db.json`.

## الملفات

- `index.html`: هيكل الواجهة والنوافذ.
- `styles.css`: تصميم RTL متجاوب للشاشات الكبيرة والصغيرة.
- `app.js`: منطق الفواتير، المخزون، الأرباح، التقارير، والحفظ المحلي.
- `server.js`: Backend محلي لتسجيل الدخول والصلاحيات وحفظ قاعدة البيانات.
- `seed.json`: بيانات أولية لإنشاء قاعدة البيانات لأول مرة.
